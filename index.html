Direktori sumber

Setiap folder judul berisi file audio langsung, tanpa subfolder audio/ atau video/. Asset video disimpan terpisah berdasarkan kategori di direktori project ./video/.

Berisi subfolder kategori seperti default, protest, car, nature, motor, dll.
Folder hasil akan dibuat sebagai output/Judul_Lagu/Judul_Lagu.mp4.

Angka lebih rendah berarti kualitas lebih tinggi.
